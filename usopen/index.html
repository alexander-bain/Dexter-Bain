How it works

Choose every winner in one complete bracket, share it, and earn more for correct late-round and upset picks.

01

Pick

Click a winner in each matchup. The player advances through the bracket and gets a fresh projection next round.

02

Share

Finish every required pick to create a read-only link containing your exact bracket.

03

Score

Correct picks are worth more each round. Underdogs below 45% can multiply that match's value up to 4×.

Scoring

Start with the round value, then multiply it for a selected underdog: 35–44% = 1.5×, 25–34% = 2×, 15–24% = 3×, and below 15% = 4×.

The percentage displayed when you make the pick sets its possible point value.
