# BlueMath Factory trailer package

This folder contains the complete production fallback for the BlueMath Factory V3 advertisements.

The live game was deployed and verified before this package was started. macOS screen capture was attempted, but the current environment does not have permission to capture the display, so an MP4 could not be rendered here. No video file is claimed as complete.

Included:

- `storyboard.md` — exact 55-second and 15-second edits
- `voiceover-script.md` — final record-ready narration
- `BlueMathFactory-Trailer-60s.srt` — main trailer captions
- `BlueMathFactory-Trailer-15s.srt` — short trailer captions
- `rendering-guide.md` — live capture URLs and exact finishing steps
- `screenshots/` — 1920×1080 stills captured from the deployed game

The game has a deterministic, save-safe trailer mode at `https://dexterbain.com/bluemath/?capture=SCENE`, where `SCENE` is `hub`, `math`, `factory`, `store`, or `victory`.
